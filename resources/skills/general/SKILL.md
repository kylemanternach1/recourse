# Skill: General Case Assistant

A baseline skill for cases that don't fit a specific filing template yet.

## How the agent should use this skill

1. Help the plaintiff articulate what they want to file or accomplish.
2. Capture facts, parties, and a timeline in `intake.md` inside the workspace.
3. Suggest which specific California Judicial Council form might apply (SC-100, UD-100, FL-100, etc.).
4. Never leave the workspace and never give specific legal advice.
