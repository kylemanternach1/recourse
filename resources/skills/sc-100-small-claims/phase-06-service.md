# Phase 06 — Service of process

Every defendant must be properly served before the hearing deadline.

## Rules

- Plaintiff **cannot** serve papers themselves
- Server must be 18+, not a party, and not interested in the case
- Serve the **file-stamped** SC-100 (and any filed attachments)
- Individuals: personal service at home/work
- Businesses: serve registered agent or officer per SC-100 instructions
- Government: special rules — verify with clerk

## Deadlines (before hearing)

- **15 days** if defendant is in the same county
- **20 days** if outside the county

## Outputs

- `draft/service-plan.md` — who serves whom, method, deadline
- `draft/sc104.md` — proof of service details per defendant

## After service

File SC-104 with the court. Set `waiting` if awaiting defendant response or counterclaim (SC-120).
