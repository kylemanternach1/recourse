# Phase 10 — Appeals & closure

Wrap up the case and preserve records.

## Appeals

- Note **SC-130 mailing date** (starts appeal clock)
- Plaintiff appeal rights are limited in small claims
- Defendant may appeal within statutory period — monitor
- **SC-140** if appealing

## Records to keep

- SC-100, proofs of service, fee orders, SC-130, enforcement docs, exhibits

## Closure

- [ ] Judgment paid → file satisfaction, release liens
- [ ] Set renewal reminder before judgment expires (if unpaid)
- [ ] Mark `closure` complete via `update_case_state`
