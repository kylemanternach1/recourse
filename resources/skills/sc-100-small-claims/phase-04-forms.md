# Phase 04 — Forms packet

Fill Judicial Council forms using verified facts from intake and `draft/damages.md`.

## Required PDF workflow

The filing artifact is a filled copy of the official Judicial Council PDF, not a
markdown draft.

1. Read `skills/pdf/SKILL.md` before working with PDF forms.
2. Confirm the official blank form exists at `ca/court_forms/sc100.pdf`.
3. Copy the official PDF into the workspace, for example:
   `draft/forms/sc100-blank.pdf`.
4. Fill the copied PDF only. Never edit files under `ca/`.
5. Save the filled form as `draft/forms/sc100-filled.pdf`.
6. Verify the filled PDF after writing by reading/extracting fields or rendering
   a check copy with the PDF skill.
7. Offer the filled PDF for download. Markdown files are supporting materials,
   not the file-ready form.

If the PDF skill or official source PDF is unavailable, do not mark `forms`
complete. Mark the phase blocked or waiting and explain what is missing.

## SC-100 field map (`draft/sc100-field-map.md`)

Map fields to Items 1–8:

1. Plaintiff name & address
2. Defendant name & address (and type)
3. Amount claimed (must match damages total)
4. Reason for claim (concise narrative — date, relationship, breach, amount)
5. Location of incident
6. Dates
7. Previous case numbers if any
8. Signature block (user signs under penalty of perjury)

## Companion forms (if needed)

- **SC-100A** — additional plaintiffs/defendants →
  `draft/forms/sc100a-filled.pdf`
- **SC-103** — defendant uses fictitious business name →
  `draft/forms/sc103-filled.pdf`

- County local cover sheet — check court website

## PDF source

Official forms: `ca/court_forms/` (for example, `sc100.pdf`). Use the PDF skill
to copy, inspect, fill, and verify the workspace copy.

## When done

Verify `draft/forms/sc100-filled.pdf` exists and has the expected field values;
verify any required companion PDFs; confirm supporting markdown has no
placeholders; then mark `forms` complete.
