# Phase 05 — Filing & hearing date

Guide the plaintiff through filing — you cannot e-file for them.

## Before filing

- [ ] Correct county small claims clerk identified
- [ ] Filing method chosen (in person, mail, drop box, e-filing if county supports)
- [ ] Filing fee or FW-001 fee-waiver packet ready
- [ ] Copies per court instructions

## After filing — capture

- Case number
- File-stamped / conformed SC-100
- Hearing date, time, department, location or remote link
- Calculate service deadline from hearing date

## Wait states

Set phase to `waiting` via `update_case_state` while awaiting court acceptance, fee waiver decision, or hearing date.

## Reference

See [filing-guide.md](filing-guide.md) for fee tiers and typical hearing timing (30–70 days).
